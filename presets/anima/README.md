# Anima専用プリセット

`LoRA Merge (Anima Knobs)`の「Anima専用（試作用）」から選択できます。
このフォルダのJSONをIMPまたはノードへドロップしても同じ値を読み込めます。
B00〜B27へ直接定義した新規プリセットです。

すべて数値は**LoRA2の割合**です。0はLoRA1のままで、LoRAを無効にする意味ではありません。
LoRA1に残したい方、LoRA2に取り込みたい方を指定してください。

| 名前 | 比率の配分 |
|---|---|
| ANIMA_BALANCED_25 | 全28階層とBASEをLoRA2 25%にする |
| ANIMA_BALANCED_50 | 全28階層とBASEを半々にする |
| ANIMA_SELF_ATTN | 自己注意70%、クロス注意・MLP15%、残り0 |
| ANIMA_CROSS_ATTN | クロス注意70%、自己注意・MLP15%、残り0 |
| ANIMA_MLP | MLP70%、自己注意・クロス注意15%、残り0 |
| ANIMA_EARLY | 自己注意・クロス注意・MLPを前段75%から後段15%へ連続的に下げる。残り0 |
| ANIMA_LATE | 自己注意・クロス注意・MLPを前段15%から後段75%へ連続的に上げる。残り0 |
| ANIMA_BASE_LIGHT | DiT28階層は0、BASEの全要素を25%にする |

BALANCED以外は、BASE_LIGHTを除きBASE=0です。
BASEはllm_adapter等を含む拡散モデルの非DiTブロック部分で、テキストエンコーダではありません。
テキストエンコーダの比率`te_ratio`はプリセットに含まれません。別途指定してください。

これらは要素ごとの寄与を比較するための**未調整の出発点**です。
画風・顔・ポーズ・ディテールの変化は実画像で未検証です。特定の効果を保証しません。
seed・プロンプト・生成条件を固定し、まずBALANCED_25と比較してください。
LoRAに含まれない要素を操作しても効果はありません。

## 用途別プリセット（追加10種）

入力は **LoRA1＝残したいB、LoRA2＝取り込みたいA** です。
プリセット欄には以下の日本語名で表示します。JSONファイル名は英語IDです。

| 表示名 | ID | 自己注意 / クロス注意 / MLPのLoRA2比率 |
|---|---|---|
| 塗り移植・弱 | ANIMA_PAINT_SOFT | 5% / 3% / 30% |
| 塗り移植・標準 | ANIMA_PAINT_TRANSFER | 10% / 5% / 55% |
| 塗り移植・強 | ANIMA_PAINT_STRONG | 20% / 10% / 80% |
| 塗り移植・顔への影響を抑える試行 | ANIMA_PAINT_FACE_GUARD | 0% / 0% / 40% |
| 柔らかい陰影を取り込む試行 | ANIMA_SOFT_SHADING | 前段5% / 3% / 30%から後段8% / 5% / 45%へ増加 |
| 色・光を取り込む試行 | ANIMA_COLOR_LIGHT | 前段8% / 5% / 40%から後段10% / 6% / 50%へ増加 |
| 線の特徴を混ぜる試行 | ANIMA_LINE_BLEND | 30% / 5% / 25% |
| 細部を混ぜる試行 | ANIMA_DETAIL_BLEND | 前段10% / 5% / 30%から後段20% / 10% / 60%へ増加 |
| ポーズを弱く取り込む試行 | ANIMA_POSE_GENTLE | 25% / 30% / 5% |
| 構図を取り込む試行 | ANIMA_COMPOSITION_BLEND | 45% / 45% / 10% |

追加10種ではnorm/proj/other/BASEを0としてB側に残します。
「塗り移植・標準」で比較し、変化が強すぎれば「弱」、顔や形の変化が気になるなら「顔への影響を抑える試行」を試してください。
同じseed・プロンプト・生成設定で、LoRA1のみ、弱、標準、強の順に比較すると差を確認できます。

**用途名は試す目的を示すもので、効果を測定した結果ではありません。**
MLPと注意機構への寄与配分を変える仮説的な出発点です。
塗り・色・顔・ポーズを独立して抽出する機能ではなく、MLPにも顔や構図の情報が含まれ得ます。
「顔への影響を抑える試行」も顔の維持を保証しません。
後段が細部を担当する等の対応も未検証です。各用途の見た目は実画像で調整してください。
LoRAにポーズ等の特徴が含まれていなければ、マージでそれを作り出すことはできません。
`te_ratio`は別設定です。まず0（BのテキストエンコーダLoRAを維持）で比較してください。
