# Anima専用プリセット

`LoRA Merge (Anima Knobs)`の「Anima専用（試作用）」から選択できます。
このフォルダのJSONをIMPまたはノードへドロップしても同じ値を読み込めます。
B00〜B27へ直接定義した新規プリセットです。

すべて数値は**LoRA2の割合**です。0はLoRA1のままで、LoRAを無効にする意味ではありません。
LoRA1に残したい方、LoRA2に取り込みたい方を指定してください。

| 名前 | 比率の配分 |
|---|---|
| ANIMA_BALANCED_25 | 全28階層とBASEをLoRA2 25%にする |
| ANIMA_BALANCED_50 | 全28階層とBASEを半々にする |
| ANIMA_SELF_ATTN | 自己注意70%、クロス注意・MLP15%、残り0 |
| ANIMA_CROSS_ATTN | クロス注意70%、自己注意・MLP15%、残り0 |
| ANIMA_MLP | MLP70%、自己注意・クロス注意15%、残り0 |
| ANIMA_EARLY | 自己注意・クロス注意・MLPを前段75%から後段15%へ連続的に下げる。残り0 |
| ANIMA_LATE | 自己注意・クロス注意・MLPを前段15%から後段75%へ連続的に上げる。残り0 |
| ANIMA_BASE_LIGHT | DiT28階層は0、BASEの全要素を25%にする |

BALANCED以外は、BASE_LIGHTを除きBASE=0です。
BASEはllm_adapter等を含む拡散モデルの非DiTブロック部分で、テキストエンコーダではありません。
テキストエンコーダの比率`te_ratio`はプリセットに含まれません。別途指定してください。

これらは要素ごとの寄与を比較するための**未調整の出発点**です。
画風・顔・ポーズ・ディテールの変化は実画像で未検証です。特定の効果を保証しません。
seed・プロンプト・生成条件を固定し、まずBALANCED_25と比較してください。
LoRAに含まれない要素を操作しても効果はありません。
